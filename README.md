# Conduit Playwright Tests

Automation testing framework for Conduit using Playwright and TypeScript. Includes API authentication, API request validation, response mocking, response modification, browser API interception, shared authentication state, and end-to-end testing practices following the Page Object Model pattern.

## Features

- API Authentication
- Perform API Requests
- Mock API Responses
- Modify API Responses
- Intercept Browser API Responses
- Shared Authentication State
- End-to-End Testing
- Page Object Model (POM)
- Reusable Test Data
- HTML Reporting

## Tech Stack

- Playwright
- TypeScript
- Node.js

## Architecture

The project follows the Page Object Model (POM) design pattern to improve maintainability, readability, and scalability of automated tests.
